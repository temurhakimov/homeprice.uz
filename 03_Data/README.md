# Данные

Рыночные данные: источники, модель данных, обработка и качество (Market Data Layer, Data Intelligence Layer).

## `sources/`
- Каталог источников: OLX, Uybor, массовая оценка, Госкомстат, сделки KMT
- Правовой статус каждого источника

## `data_model/`
- Схема данных: объявление, объект, дом, район, аналог, оценка

## `pipeline/`
- Сбор, очистка, нормализация, дедупликация, геокодирование

## `quality/`
- Правила контроля качества, выбросы, битые цены, метрики качества

## `historical_db/`
- Историческая база: хранение истории цен, версии, архив
