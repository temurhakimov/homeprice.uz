# Движок оценки

Математическая реализация методологии (Comparable Selection Engine, Valuation Engine).

## `comparable_selection/`
- Поиск, фильтрация и ранжирование аналогов

## `models/`
- Математические модели: корректировки, регрессия, взвешивание, диапазон

## `confidence/`
- Уровень достоверности результата, условия отказа в оценке

## `tier1_quick_calc/`
- Упрощённая модель уровня 1
