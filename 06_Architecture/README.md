# Архитектура

Системная архитектура платформы KMT Real Estate Analytics, инфраструктура, API, безопасность.

## Документы в этой папке
- System_Architecture.md — 10 компонентов платформы и их связи

## `adr/`
- Architecture Decision Records — по одному файлу на решение

## `api/`
- Спецификации API (внутренние и B2B)

## `infrastructure/`
- Хостинг, окружения, деплой, мониторинг, резервные копии

## `security/`
- Безопасность, доступы, хранение персональных данных
