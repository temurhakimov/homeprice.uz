# KMT HomePrice.uz: контекст для ассистента

Онлайн-оценка квартир в Ташкенте. Проект ведёт Bizzone Group (резидент IT Park с 2018 г.), KMT — партнёр (модели оценки, оценщики). Владелец — Темур Хакимов, руководитель проекта. Команда: Эркинов Азизбек — главный программист и разработчик; Равшан Навруз-зода — директор Bizzone Group, компаньон, отвечает за юридические аспекты.

## С чего начать
1. `README.md` — структура документации.
2. `00_Overview/00_Project_Overview.md` — концепция и три уровня продукта.
3. `00_Overview/Stage1_Plan.md` — план этапа 1 (задачи A–M = задачи в ClickUp) и главный принцип: до pd.gov.uz персональные данные не собираются.
4. `00_Overview/analysis/README.md` — стратегические анализы (PEST, пять сил, SWOT, 4P, JTBD, CJM, сравнения отчётов и дизайна, план ClickUp, назначения, расширение по странам), журнал решений, статус действий и единый список открытых вопросов.

## ClickUp
Папка «HomePrice.uz — Этап 1» (Space, folder 1100370000126958): списки A–M, 110 задач (92 из `Stage1_Plan.md` + 18 новых по итогам анализа), имена вида «B1 · …». A1 и A12 закрыты; D10 ждёт решения владельца, L7 без чисел. Изменения внесены по `00_Overview/analysis/11_ClickUp_Change_Plan.md`; назначение ответственных — `12_Assignment_Plan.md` (на момент записи применено только к A2, остальное делает запланированная задача; проверять assignees в ClickUp; у ClickUp MCP дневной лимит 300 вызовов). Читать задачи можно через ClickUp-коннектор (clickup_search, clickup_filter_tasks).

## Принципы
- Стоимость квартиры считают математические модели по ЕНСО / НСО №10, не AI. AI — только ассистент.
- Различать цены предложения (объявления) и цены сделок; не обещать точность, которую не измерили.
- Помечать утверждения тегами [факт] / [гипотеза] / [проверить]; в анализах давать расхождения мнений и самокритику.
- MVP: только квартиры Ташкента; не усложнять требованиями, которые нужны не первому рынку.
- Язык документов — русский.

## Рабочие правила
- Решения владельца вносить в `00_Overview/analysis/08_Decisions_and_Content_Plan.md` с датой.
- Ничего не коммитить, не писать в ClickUp и не отправлять наружу без просьбы владельца. В этой папке git не может удалять файлы: при коммите оставляет lock-файлы; их переименовывать (`mv .git/index.lock .git/stale-index-lock`), не удалять; коммитить с идентичностью владельца (`git -c user.name=… -c user.email=…`).
- Если советы из `analysis` противоречат `Stage1_Plan.md`, действует Stage1_Plan (про персональные данные).
- Заявки и тесты у конкурентов (STAI) выполнять без оплаты и только по прямой просьбе.
