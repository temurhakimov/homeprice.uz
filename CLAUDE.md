# KMT HomePrice.uz: контекст для ассистента

Онлайн-оценка квартир в Ташкенте. Проект ведёт Bizzone Group (резидент IT Park с 2018 г.), KMT — партнёр (модели оценки, оценщики). Владелец — один человек (юрист, финансист, разработчик в одном лице).

## С чего начать
1. `README.md` — структура документации.
2. `00_Overview/00_Project_Overview.md` — концепция и три уровня продукта.
3. `00_Overview/analysis/README.md` — стратегические анализы (PEST, пять сил, SWOT, 4P, JTBD, CJM), журнал решений, статус действий и единый список открытых вопросов.

## Принципы
- Стоимость квартиры считают математические модели по ЕНСО / НСО №10, не AI. AI — только ассистент.
- Различать цены предложения (объявления) и цены сделок; не обещать точность, которую не измерили.
- Помечать утверждения тегами [факт] / [гипотеза] / [проверить]; в анализах давать расхождения мнений и самокритику.
- MVP: только квартиры Ташкента; не усложнять требованиями, которые нужны не первому рынку.
- Язык документов — русский.

## Рабочие правила
- Решения владельца вносить в `00_Overview/analysis/08_Decisions_and_Content_Plan.md` с датой.
- Ничего не коммитить и не отправлять наружу без просьбы владельца.
- Заявки и тесты у конкурентов (STAI) выполнять без оплаты и только по прямой просьбе.
