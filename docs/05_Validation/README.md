# Валидация моделей

Проверка точности: бэктесты, метрики, калибровка. Доказательная база для пользователей, банков и партнёров.

## `backtests/`
- Бэктесты на архиве KMT и реальных сделках

## `metrics/`
- Метрики точности: медианная ошибка, доля в ±X%, по районам и сегментам

## `calibration/`
- Журнал калибровок модели и их результатов

## `offer_vs_deal/`
- Цена предложения против цены сделки: коэффициент торга
