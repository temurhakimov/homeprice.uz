# Операции и CRM

Процессы KMT вокруг продукта: заявки, CRM, поддержка.

## `crm_integration/`
- Интеграция с CRM KMT: поля, статусы, передача лидов

## `order_process/`
- Процесс заказа профессиональной оценки: заявка → выезд → отчёт

## `support/`
- Поддержка пользователей, обработка обратной связи и жалоб
